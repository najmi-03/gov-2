Setup Required

Supabase belum dikonfigurasi. Ikuti langkah berikut:

  1. Buat akun gratis di supabase.com
  2. Buat project baru (pilih region terdekat: Singapore)
  3. Buka SQL Editor → jalankan isi file setup.sql
  4. Buka Storage → buat bucket baru bernama portfolio (set Public)
  5. Buka Authentication > Users → tambah user dengan email portofolionajmi@gmail.com
  6. Buka Settings > API → copy Project URL dan anon key
  7. Paste ke file supabase-config.js
  8. Refresh halaman ini
